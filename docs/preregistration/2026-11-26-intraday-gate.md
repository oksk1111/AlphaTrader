# 사전 등록: 장중 점수 엔진 실데이터 판정 (2026-11-26)

이 문서는 서버 데이터로 판정을 돌리기 **전에** 커밋한다. 결과를 본 뒤 기준·파라미터를 바꾸지 않는다.

## 대상

- `modules/intraday_strategy.py` 를 `user_config.json` 의 `intraday_strategy` 설정 그대로 쓴다
  (min_buy_score 0.62, min_overnight_score 0.72, max_spread_pct 0.35). 이 데이터로 파라미터를 고르지 않는다.
  파라미터를 데이터에 맞추지 않았으므로 수집 기간 전체가 표본 밖(out-of-sample)이다.
- 유니버스: 로테이션 유니버스 (KR 17종, US SPY·QQQ·SMH·IWM·XLK). 시장별로 따로 판정한다.
- 체결: 개장 30분 뒤부터 1분마다 평가하고, 매수 신호가 나면 다음 분봉 시가에 산다. 종목·세션당 1회.
  당일 종가에 판다. 오버나잇 판정이 나면 다음 세션 첫 분봉 시가에 판다.
- 비용 (왕복): KR 0.23%, US 0.60%.

## 데이터 유효성 (하나라도 못 넘으면 "판정 불가" — 통과도 기각도 아니다)

- 분봉 시각대 추정 후 정규장 안 분봉 비율 ≥ 80%
- 정규장 분봉이 50% 이상 찬 세션 ≥ 20

## 채택 기준 (시장별, 전부 만족해야 통과)

1. 기존 게이트: 거래 ≥ 20, 비용 후 기대값 > 0, profit factor > 1, MDD ≥ −10%
2. 비용 1.5배에서도 기대값 > 0
3. 가장 좋은 거래 1건을 빼도 기대값 > 0
4. 기준선보다 낫다: 같은 종목·세션에서 개장 30분 뒤 시가에 사서 종가에 파는 전략의 비용 후 거래당 기대값보다
   엔진의 거래당 기대값이 크다 (신호가 시장 흐름 이상의 정보를 주는가)
5. 세션을 앞·뒤 절반으로 나눴을 때 두 구간 모두 기대값 > 0

## 결과에 따른 행동

- **통과:** 실주문 자격이 아니라 **소액 실험 자격**이다. 20여 세션은 통계적으로 짧다. `live_enabled` 는 사용자 확인 후
  별도 커밋으로만 켜고, 정규장 로테이션의 Sharpe·MDD 를 악화시키면 끈다 (v8.6 규칙 1).
- **기각:** 장중 경로는 닫는다. 같은 데이터로 파라미터를 다시 맞추지 않는다 (과적합). 새 후보는 새 사전 등록과
  이 날짜 이후 데이터로만.
- **판정 불가:** 데이터 수집 결함부터 고친다.

## 공개 로그

저장소가 PUBLIC 이다. Actions 로그에는 시장별 집계(세션·거래 수, 비율 %)만 찍는다. 가격·계좌 값은 찍지 않는다.
